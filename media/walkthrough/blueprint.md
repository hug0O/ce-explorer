# See your code as a graph

**Blueprint: file** draws the routines of the file as nodes and the calls as wires: drag from one node to another to write a call, click a wire and press Delete to remove it, F2 to rename. **File | Project** at the top left switches to the units of the whole project and their `uses` (Delphi).

Click a node to light what calls it (blue) and what it calls (orange); **hide others** keeps only those.
