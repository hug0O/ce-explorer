# The structure of the file

The **Code Explorer** view lists the classes, methods, fields, headings or labels of the file you are editing, in any of the languages the extension reads.

- Click a member to go to it, press **F2** to rename it, **E** to edit it, **Delete** to remove it.
- The filter box stays at the top while the list scrolls.

Shortcut: **Ctrl+K Ctrl+M**.
